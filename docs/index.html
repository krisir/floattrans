正在输入

停下输入片刻后，英文会出现在浮动框里。

工作方式

三步闭环，全程自动

  1. 01

    捕获当前句

    通过辅助功能读取当前输入框，按中文及中英文标点识别正在编辑的句子。

  2. 02

    选择翻译引擎

    使用 macOS Translation 本地语言包，或切换到 OpenAI 兼容、Claude、DeepSeek、GLM 和自定义 API。

  3. 03

    浮动显示

    英文以字幕式浮动框出现，不抢焦点、可手动关闭，支持位置、字号与自动隐藏。

v0.3.0

这次更新了什么

  • 多语言翻译

    源语言和目标语言可独立选择中文、英语、日语、俄语、韩语、法语、德语和西班牙语。

  • 本地 / API 双引擎

    可使用 macOS 本地翻译，或配置多个大语言模型端点并按顺序自动故障切换。

  • 历史默认不记录

    默认不保存翻译历史；需要时可选保留期限，也可确认后删除全部记录。

  • Markdown / Excel 导出

    历史记录可按日期导出为 Markdown 或 Excel，列为「序号 / 原文 / 译文」。

  • 设置窗口可达

    打开设置时显示 Dock 图标，可用 Dock 或 Cmd+Tab 回到设置，不必再找菜单栏。

功能

为长时间写作而设计

按句实时更新

同一句会动态刷新；新句子可叠放新浮动框。最多同时保留 3 个，每个都可关闭。

可调 Overlay

右上角、底部居中、右下角；边距、字号、自动隐藏 5–60 秒或永不隐藏。

应用排除

通过文件选择器添加不想翻译的 App，密码等安全输入框始终跳过。

模型配置

API 密钥存入 macOS 钥匙串；模型、端点、提示词、思考模式和排序可在设置中编辑。

隐私优先

默认可走系统本地能力；切换 API 时，文本只发送到你配置的服务商。调试日志只留在本机，且不记录密码内容。

隐私

本地优先，自选 API

浮译需要辅助功能权限才能读取当前文本框的内容，但不会读取密码字段。本地翻译不会上传文本；切换 API 翻译时，文本会发送到你配置的服务商。

  • 跳过 Secure TextField / 密码框
  • API Key 存入 macOS 钥匙串
  • 历史记录保存在本机 SQLite
  • 可选排除敏感应用

开始使用

安装与首次设置

下载安装包

打开 DMG，把 FloatTrans.app 拖进 Applications。当前为 ad-hoc 签名、未经公证，首次打开请右键 → 打开。

下载 FloatTrans-0.3.0.dmg

系统要求

  • macOS 15 或更高版本
  • Accessibility（辅助功能）权限
  • 本地翻译需要对应语言包；API 翻译需要服务商密钥

从源码构建

git clone https://github.com/krisir/floattrans.git
cd floattrans
zsh Scripts/build-app.sh
open FloatTrans.app

磁盘上的应用包名为 FloatTrans.app；用户可见显示名是「浮译」。也可打 DMG： zsh Scripts/build-dmg.sh

  1. 启动后在引导页打开辅助功能设置并授权。
  2. 在设置中选择源语言、目标语言和本地或 API 翻译引擎。
  3. 在 TextEdit、浏览器等支持辅助功能的输入框中输入所选源语言。默认停下片刻即可看到译文浮动框；也可改成完整句子或快捷键触发。
